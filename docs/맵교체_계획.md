# 맵 전면 교체 계획 (2026-08-02)

`design/맵/` 의 AI 일러스트 배틀맵으로 네 맵(본부·거리·저택·지하 수로)을 모두 갈아끼운다.
마감은 8/7 이므로 **오려내기 작업 없이 배경 한 장 + walk 마스크 한 장**으로 끝내는 것이 원칙이다.

확정된 방향 세 가지 (2026-08-02 사용자 결정):

1. 가구 있는 **완성 맵을 그대로 배경으로** 굽는다. 소품 시트는 상태가 바뀌는 것(저택 연구실 문)만 쓴다.
2. **스테이지 3 은 수로 형태에 맞춰 전면 재설계**한다 (검문소·순찰로·아이 위치).
3. **네 맵의 규격을 통일**한다 — 본부의 0.3배 축소 꼼수를 없앤다.

---

## 1. 공통 규격 — 이번 교체의 좌표 계약

지금까지 맵마다 제각각이던 축척을 하나로 못박는다.

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 배경 | **원본 해상도 1:1** (`setScale` 없음) | 축소하면 월드가 카메라보다 작아져 탐색이 사라진다 (본부가 그 사례) |
| `tileSize` | **32** (전 맵) | 그림의 자체 칸(≈64~70px)의 절반 → 들쭉날쭉한 AI 아트에 충돌을 촘촘히 맞출 수 있다 |
| 캐릭터 크기 | 맵 JSON 의 **`charHeight`** (월드px) | 그림마다 내부 축척이 달라 맵별로 다른 값이 필요하다 |
| 카메라 줌 | 맵 JSON 의 **`cameraZoom`** (정수) | 아래 |
| `cols`/`rows` | `floor(배경폭/32)` × `floor(배경높이/32)` | 아래 표 |
| 충돌 | `props.walk` **단일 출처** | 기존 계약 유지 (`worldParts.buildColliders`) |

**줌이 왜 맵마다 달라야 하는가** — `charHeight` 는 *그림의 축척*이 정하고, 화면에 인물이 몇
명분 보이는지는 **둘의 곱**이 정한다. 본부를 charHeight 96 · 줌 2 로 띄웠더니 세로로 인물
5.6명분밖에 안 보여 코앞만 보였다 (실측). 눈에 맞는 구간은 **`charHeight × cameraZoom`
≈ 100~130** — 세로로 8~11명분이다. 본부는 96×1, 거리는 64×2 로 둘 다 그 구간에 든다.

### 맵별 치수

| 맵 | 원본 | 손질 | 칸 | 배경 파일 |
| --- | --- | --- | --- | --- |
| 본부 | 1920×1280 | 없음 (이미 적용됨) | **60×40** | `hq-bg.png` (그대로) |
| 거리 | 2240×1120 | 워터마크 제거 | **70×35** | `street-bg.png` (교체) |
| 저택 | 1872×1264 | 좌측 검은 여백 16px 잘라내고 하단에 16px 덧댐 → 1856×1280 | **58×40** | `mansion-bg.png` (교체) |
| 지하 수로 | 1728×1344 | 워터마크 제거 | **54×42** | `escape-bg.png` (신규) |

거리·수로·본부는 32 로 정확히 나눠떨어진다. 저택만 어긋나는데, **잘라내기만으로는 안 된다** —
세로 검은 여백이 위 12px·아래 0px 뿐이라 16px 을 자르면 현관 포치가 잘린다. 좌측 여백은 156px 이라
넉넉하므로 **가로는 자르고 세로는 덧댄다**.

### charHeight · cameraZoom

**실플레이로 정한다** — 이 둘이 이번 작업에서 유일하게 "눈으로만 정할 수 있는" 수치다.
`node tools/shot.mjs "/?tutorial" --wait 7000 -o hq.png` 로 실제 화면을 찍어 보면 된다.

| 맵 | charHeight | cameraZoom | 기준으로 삼은 것 |
| --- | --- | --- | --- |
| 본부 | **96** | **1** | ✅ 확정. 작업대·모래주머니·화로 옆에 섰을 때 사람 크기가 맞는다 |
| 거리 | 64 (초안) | 2 (초안) | 공원 벤치 64px, 건물 문 ≈60px |
| 저택 | 88 (초안) | 1 (초안) | 식당 의자·복도 폭 3칸 |
| 지하 수로 | 88 (초안) | 1 (초안) | 돌길 통로 폭 2~3칸 |

씬 상수(`PLAYER_HEIGHT`·`OFFICER_HEIGHT`·`ALLY_SPRITE_SCALE`·이름표 y·말풍선 높이·걷는 속도·
상호작용 사거리)는 옛 축척에 맞춘 절대 픽셀이라 **전부 charHeight 비례로 바꿨다** — 맵 하나를
갈아끼울 때 고칠 곳이 맵 json 한 줄이 되도록. 32px 에서는 예전 값과 정확히 같은 수가 나온다.

> 포아송이 통했던 것이고, 그림이 다르면 방법도 다르다.

## 3. 작업 순서

### 커밋 0 — 공통 토대 (맵을 건드리기 전에)

교체 도중 계속 발목 잡을 것들을 먼저 없앤다.

1. **`charHeight` 도입** — 맵 JSON 에 넣고 `worldParts.createPlayer` 가 읽는다.
2. **플레이어 충돌체를 축척에 묶는다** — `worldParts.js:186` 의 `setSize(16,14).setOffset(8,16)` 은
   절대 픽셀이라 타일 9.6px 인 본부에서 1.7칸짜리로 뜬다. `charHeight` 비례로 계산하도록 고친다.
3. **`EndingScene.js:86` 버그** — `hqProps.blocked`(배열)를 넘기고 있어 walk 마스크가 통째로 무시되고
   있다. 엔딩 씬에는 사실상 가구 충돌이 없다. `hqProps` 로 고친다.
4. **`PATROL_ROUTES` 를 공유 모듈로** — 지금 `Patrol.js:50` 과 `check-spawn-safety.js:16` 에 **손으로 두 번**
   적혀 있다. 거리 좌표를 갈아엎을 참이라 이대로 두면 검사가 옛 순찰로를 재는 걸 눈치채지 못한다.
5. **`Patrol.js:36` 의 두 진실** — 거리 충돌은 `walk` 를, 거리 시야(LoS)는 `layout` 의 solid 를 본다.
   새 마스크를 칠하는 순간 로봇이 벽을 뚫어 보게 된다. `makeBlockedLookup(mapData, streetProps)` 로 통일.
6. **아트 반입 도구** — `tools/webp2png.py`(원본 webp 풀기) + `scripts/import-map-art.js`
   (워터마크 제거 · 32의 배수로 자르기 · 칸 수 보고). 셋 다 `--dry` 로 검증 완료.

`walkmask.js seed`(§4)는 **커밋 2 로 미뤘다** — 색 규칙은 맵마다 다르고, 실제 그림을 놓고
맞춰야 정해진다. 기계 없이 미리 짜면 두 번 짜게 된다.

### 커밋 1 — 본부 규격 통일 (가장 작다, 규격 검증이 목적)

그림은 그대로다. 칸 인덱스(60×40)도 그대로라 **손으로 칠한 `hq-props.json` 의 walk 를 그대로 재사용**한다.

- `hq.json`: `tileSize` 9.6 → **32**, `charHeight: 96` 추가, `_comment` 갱신
- `TutorialScene.js`: `BG_SCALE` 0.3 → 1 (삭제), `CAMERA_ZOOM` → 2, `PLAYER_HEIGHT`/`OFFICER_HEIGHT`/
  ALLY 크기 재조정, 카메라 고정(`stopFollow`+`centerOn`) 해제 → 플레이어 추적
- `EndingScene.js`: 같은 값으로 맞춤 (커밋 0 의 버그 픽스와 함께)
- **검증**: `npm run dev` → `?nointro` 로 본부 실플레이. 여기서 charHeight 규격이 맞는지 눈으로 결론이 난다.
  안 맞으면 §1 의 초안 표를 여기서 고치고 나머지 맵에 적용한다.

### 커밋 2 — 거리 (좌표 의존이 가장 많다)

60×48 → **70×35**. 세로가 짧아지고 가로가 길어져 순찰 축이 전부 바뀐다.

- 배경: 워터마크 제거 → `street-bg.png` (2240×1120)
- `map.json`: `cols`70 `rows`35 `tileSize`32 `charHeight`64. `layout` 은 walk 마스크가 우선이라
  바깥 테두리만 solid 로 두면 된다
- walk 마스크: `seed street` (자갈·잔디=걷기, 건물·소품=막힘) → 손보정 → `import street`
- **재배치할 좌표** — 새 광장 그림 기준
  - `spawns.player` / `spawns.allies[5]` / `spawns.broker` / `spawns.citizens[5]` / `spawns.jail`
  - `cage` — 새 그림 좌하단에 **창살 건물이 그려져 있다**. 이걸 임시 감옥으로 삼는다
  - `PATROL_ROUTES` 4개 — 시계탑 둘레 순환로 + 광장 외곽으로 다시 긋는다
  - `street-props.json.vents` — 증기 발생 지점. 새 그림의 굴뚝·배관 위치로
- **죽은 데이터 정리**: `sectors`/`plazas`/`buildings`/`trees`/`lamps` 는 은퇴한 절차적 아트 스크립트
  전용이라 아무도 안 읽는다. 지우거나 주석으로 사망 선고를 남긴다
- **검증**: `node scripts/check-spawn-safety.js` (동료 스폰이 순찰 반경 244px 밖인지) + 실플레이

### 커밋 3 — 저택 (방·문 구조가 서버까지 연결된다)

60×35 → **58×40**.

- 배경: 좌16 잘라내고 하16 덧대 1856×1280 → `mansion-bg.png`
- walk 마스크: **`mansion_floorplan_collision_map.webp` 의 밝기 임계로 시드**(흰 바닥=걷기, 나무·돌=벽)
  → 완성본과 diff 해 가구를 막고(카펫·바닥 무늬는 걷기로 남겨야 하니 색상으로 거른다) → 손보정
- `mansion.json` `rooms[]` 10개를 새 도면에 다시 적는다. 다행히 기존 id 가 거의 그대로 대응한다:

  ```
  laundry 좌상(빨래)  kitchen 좌중(화덕)   저장고 좌하(통·자루)
  hall    중앙하(붉은 카펫)  dining 중앙(긴 식탁)  corr 중앙 세로 복도
  office  우상(집무 책상)    library 우중(책장)    lab  우하(황동 증류기)
  ```
  남는 건 `locked`(잠긴 방)와 `walk`(연구실 앞 통로) 를 어디로 둘지 — 우측 상단 아치방이 후보다.
- `doors[]` 8개 재배치. `key:'lab'` 문은 `#syncLabDoor` 가 **정확한 중심 좌표로 static body 를 지우므로**
  그 칸이 walk 마스크에서 반드시 막혀 있어야 한다. `mansion-door-open.png` 는 `door_sprite_sheet` 의
  아치문으로 교체(문 폭이 바뀌면 `w`/`h` 도 같이)
- **`src/data/mansion.json` 도 같이** — `npcs[].{room,col,row}` · `objects[].{room,col,row}` · `escort`.
  서버(`mansionSession.js`)가 이 값을 그대로 클라이언트에 내보내므로 여기가 틀리면 NPC 가 벽에 박힌다
- `MansionScene.js` 하드코딩: `DOCUMENT{53,22}` · 스팀 vent 픽셀 4개 · `FADE_INTO_HALL` · `ALWAYS_LIT`
- **검증**: `npm run smoke:mansion` (좌표 무관하지만 npc id 계약 확인) + 실플레이로 방 그림자·문 열림

## 4. walk 마스크 자동 초안 — `walkmask.js seed <맵>`

이번 작업에서 시간을 가장 크게 아끼는 부분이다. 본부는 1242칸을 손으로 적었고 그마저도 바닥
절반이 막혀 있었다. 이번 리소스는 **색이 이미 갈려 있어 기계가 초안을 뽑을 수 있다.**

| 맵 | 시드 규칙 |
| --- | --- |
| 저택 | 충돌도의 밝은 회백 = 걷기, 나무·돌 = 막힘, 검정 = 밖. + 완성본 diff 로 가구 막기 |
| 수로 | 색상각으로 분리 — 물(청록: G·B > R) = 막힘, 돌길(황갈: R > G > B) = 걷기 |
| 거리 | 빈 맵의 자갈·잔디 = 걷기, 건물 = 막힘. + 완성본 diff 로 소품 막기 |
| 본부 | 이미 손으로 칠한 마스크가 있다. 빈 맵 diff 로 재검증만 |

출력은 기존 `template` 과 같은 `design/walkmask/<맵>-walk.png` 라서 **손보정 → `import` 흐름이 그대로**다.
시드는 초안이지 답이 아니다 — `import` 가 내는 `<맵>-walk-applied.png` 의 **노랑(걸을 수 있는데 스폰에서
못 닿는 섬)** 이 0 이 될 때까지 고쳐 칠한다.

## 5. 검사

기존 3종 계약을 유지하되, 그리기 패스가 없어진 만큼 ③은 대체한다.

1. **도달성(BFS)** — `walkmask.js import` 의 flood 가 스폰에서 못 닿는 섬을 노랑으로 보고한다.
   저택의 잠긴 연구실처럼 의도된 섬은 예외로 적어 둔다
2. **스폰 안전** — `check-spawn-safety.js` (거리). 순찰로 공유 모듈화 후 재실행
3. **검문소 시야** — `npm run check:escape` (수로). 이번 재설계의 통과 조건
4. **회귀** — `npm run smoke:tutorial` · `smoke:mansion` · `smoke:escape` · `npm run build`

## 6. 리스크

- **번들 크기** — 배경 4장이 PNG 로 ~9.5MB 가 된다(현재 6MB). `scripts/png.js` 의 적응형 행 필터가
  이미 3.0→1.6MB 를 내던 실적이 있으니 먼저 그걸 태우고, 그래도 크면 배경만 webp 로 내보낸다
  (브라우저는 읽지만 Node 도구가 못 읽으므로 `design/` 아래 PNG 사본을 도구용으로 남겨야 한다)
- **저택 방 id 가 서버까지 이어진다** — `src/data/mansion.json` 의 `room` 문자열이 `mansion.json` 의
  `rooms[].id` 와 어긋나면 아무도 검증해 주지 않고 조용히 깨진다. 커밋 3 에서 반드시 한 번에 고친다
- **`walk.length === rows` 불일치** — 어긋나면 `buildColliders` 가 **경고 없이** 옛 layout 경로로 되돌아간다.
  칸 수를 바꾸는 이번 작업에서 가장 조용한 사고다. 커밋 0 에서 불일치 시 예외를 던지게 만든다
- **charHeight 는 눈으로만 정해진다** — 커밋 1(본부)에서 결론을 내고 나머지에 적용한다.
  여기서 헤매면 뒤가 다 밀린다
