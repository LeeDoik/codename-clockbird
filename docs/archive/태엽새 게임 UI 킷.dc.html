전 화면 공통 계약
■id 고정 — #dialogue #dialogue-portrait #dialogue-speaker #dialogue-text #dialogue-input #dialogue-field #dialogue-send #dialogue-code #dialogue-hint. .visible · .no-portrait 토글 동작 유지.
■치수 — 전부 calc(N * var(--s)), --s: calc(100cqw / 1920). --s 는 #game-root 가 아니라 그 자식에 선언했다. px 고정 없음.
■색 — theme.js 짝 토큰만: brass-hi / brass / brass-lo / leather / ink / paper / paper-dim / patina(성공) / wax(실패·경보).
■배경 에셋 — 타이틀만 도트 일러스트 1장(assets/title-city.png)을 깐다. UI 는 이미지 색에 의존하지 않고 위 토큰만 쓰므로, 배경을 갈아도 UI 는 그대로 성립한다. image-rendering:pixelated 필수.
■본문 26px@1920 이상 — 캔버스 HUD 22px 보다 커야 위계가 서지 않는다. 대화 본문 30px.
■되돌릴 수 없는 것만 황동 — 접선 코드 전달·접수·전달한다. 되돌릴 수 있는 대화/닫기는 어둡게. 버튼에 키 병기.
■초상 슬롯 — public/portraits/<id>.png, 반신 4:7 (640×1120+), 투명 PNG, 화면 높이 약 80%. 얼굴은 상단 30% 안. 파일이 없어도 슬롯 프레임으로 멀쩡하다.
