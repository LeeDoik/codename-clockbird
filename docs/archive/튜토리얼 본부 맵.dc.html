맵 명세
■34×20 타일 · 타일 16px · 실내 탑뷰. 튜토리얼이므로 카메라 이동 없이 한 화면에 다 들어온다(p.6) — 무기고 · 지휘 테이블 · 작전 게시판 · 취사 구석 · 계단, 다섯 구역이 두꺼운 석벽으로 나뉜다. 줌을 올리면 카메라가 플레이어를 따라간다.
■아트 규칙 — 거리·저택 맵과 같은 5단 램프 문법(외곽선 + 상단 하이라이트 + 바닥 그림자, 광원 좌상단). 다만 조명은 따뜻한 톤으로 깔아 바깥의 차가운 강철 세계와 대비시킨다(p.6). 화덕과 배관에서 증기가 오른다.
■배치 — 간부는 중앙 지휘 테이블 앞에 고정되어 동선을 유도하고, 동료 3명은 무기고 · 게시판 · 취사 구석에 흩어져 있다. 동료는 각자 색상 · 분류 · 대중적 특징 힌트를 하나씩 준다(p.10).
■대화 UI — NPC 근접 시 머리 위 상호작용 표시, 대화 시 좌측 하단 초상 슬롯 + 하단 대사 바 + 우측 세로 선택지(대화하기 / 접선 코드 / 닫기)(p.7). 접선 코드는 자유 입력. NPC별 신뢰도 2, 2회 틀리면 그 동료가 단어를 떠올린 이유를 말하고 코드 접수를 멈춘다. 셋 다 0이면 간부 앞으로 자동 이동 → 새 접선 코드로 재시작(p.11).
