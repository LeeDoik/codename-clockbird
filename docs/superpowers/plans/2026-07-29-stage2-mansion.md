## 4. 규칙 (서버)

### 4.1 상태

NPC별 개별 카운트다 — 저택 합산이 아니다 (수정안 p.22 [확정]).

```
npc: { id, kind: 'ally'|'civ'|'escort', favor: 0, suspicion: 0, halted: false, gave: false }
session: { sessionId, npcs, pieces: [], hasKey: false, cleared: false, over: null }
```

### 4.2 성향 판정

대화 스트리밍과 **분리된 별도 Haiku 호출**이다 (계획서 §5.1 #4 — 스트리밍 경로를 건드리지 않는다).
응답 직후 비동기로 돌린다. 수치는 UI에 노출하지 않는다.

플레이어 발언 → `{ stance: 'anti' | 'pro' | 'neutral' }`

| 발언 | 동료 | 민간인 |
|---|---|---|
| anti (반브루주아) | 호감도 +1 | 의심도 +1 |
| pro (친브루주아) | 의심도 +1 (호감도 봉쇄) | 변화 없음 |
| neutral | 변화 없음 | 변화 없음 (중립 정보 제공) |

### 4.3 임계

| 조건 | 결과 |
|---|---|
| 동료 호감도 3 | **정보 조각 획득** (`pieces` 에 추가, `gave: true`) |
| 동료 의심도 3 | 대화 중단(`halted`). **다른 NPC와 1회 대화하면 해제**, 호감도는 0부터 |
| 민간인 의심도 3 | **밀고 → 즉시 게임오버** |
| 정보 조각 3개 | **연구실 열쇠 획득** — 서재 동료가 마지막이 아니어도 3개 모이면 준다 |
| 열쇠 + 연구실 문서 열람 | **클리어** (입장만으로는 아님 — 수정안 p.20 [확정]) |

민간인이 순수 리스크면 최적 행동이 "민간인 무시"가 되어 5명이 지뢰 장식이 된다(계획서 §4.4).
그래서 neutral 발언에는 **방 배치·동료 소재의 옅은 힌트**를 준다 — 프롬프트에 그 지시를 넣는다.

### 4.4 엔드포인트

`src/server/routes/mansion.js` — `routes/stage.js`의 모양을 그대로 따른다.

| 경로 | 내용 |
|---|---|
| `POST /api/mansion/start` | 세션 생성. LLM 호출 없음 → 즉시 응답 (스테이지 1과 달리 대기 없음) |
| `POST /api/mansion/talk` | SSE 스트리밍 대화. 응답 완료 후 성향 판정 → 상태 변화를 마지막 이벤트로 흘린다 |
| `POST /api/mansion/document` | 문서 열람 → 클리어 판정 |

`ai/dialogue.js`의 스트리밍과 `ai/guardrail.js`를 재사용한다.
**유출 금지**: `/talk` 응답에 favor/suspicion 수치를 절대 싣지 않는다 — 스테이지 1의
`/contact` reason 유출 버그(5ef7f75)와 같은 실수를 반복하지 않는다. 화이트리스트로 내보낸다.

## 5. 클라이언트

`src/client/scenes/MansionScene.js` — `TutorialScene`을 뼈대로 삼는다 (규칙이 씬에 있고
발밑은 `worldParts`에서 빌리는 구조가 같다).

- `buildTilemap` / `createPlayer` / `applyMovement` / `nearestOf` / `setupCameras` 그대로 재사용
- **대화창 규약 준수**: 플레이어가 누른 순간 여는 창은 `show()`, 응답이 도착한 순간 여는 창은
  `reply()`. 클리어 대사는 일부러 `show()` (넘기면 안 되는 대사)
- 초상은 `opts.portrait`로 넘긴다 — NPC id가 곧 `public/portraits/<id>.png`
- **`setupCameras` 호출 시점 규약**: 월드를 다 깐 직후, UI 만들기 전. 이후 생성물은
  `asWorld()`/`asUi()`로 소속을 밝힌다
- 방 이름 표시 — 플레이어가 들어간 방 이름을 화면 상단에 잠깐 띄운다 (원본의 방 정보 카드를
  간소화한 것). 60×34 맵에서 길을 잃지 않게 하는 최소 장치
- HUD: 획득한 정보 조각 수 / 열쇠 보유 여부
- 진입점: `?stage2` 개발 플래그로 곧장 들어간다. 정식 연결은 스테이지 1 클리어 직후

## 7. 이번 범위 밖

- **끝말잇기 확인 테스트** — 호감도 임계 = 즉시 정보 조각으로 대체. 루프는 닫힌다
- **경비 로봇·발각 게이지** — D1. 스테이지 3의 차별점으로 남긴다
- **전용 스프라이트** — 기존 `chars.png` 재사용
- **잠긴 방 내부** — 영구 잠김. 문 앞에서 기계음 대사만 (스테이지 3 복선)
- **저택 진입/탈출 연출** — 스테이지 1→2 전환은 즉시 전환으로 두고, 연출은 시간이 남으면

## 8. 위험

| 위험 | 대응 |
|---|---|
| 성향 판정이 애매한 발언에서 흔들린다 | 판정 불명 시 `neutral` 로 떨어뜨린다 — 오판으로 게임오버되는 쪽이 훨씬 나쁘다 |
| 민간인 의심도 3 = 즉시 게임오버가 가혹하다 | 첫 의심 발언에 NPC가 **경고 대사**를 한다. 실플레이 후 임계를 4로 올릴 여지를 남긴다 |
| 60×34 맵이 걸어서 지루하다 | 홀↔복도가 직결이라 중심축이 짧다. 실측 후 이동 속도를 200→240 조정 검토 |
| 7일 안에 안 끝난다 | 태스크 1~5(서버 없는 부분)까지만 끝나도 "저택을 걸어다니는 화면"은 영상에 담긴다 |
