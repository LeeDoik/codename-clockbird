태엽새 / HEART OF STEEL

게임 소개 및 설명 문서 · 코드네임 codename-clockbird

증기기관 도시의 잠입 요원이 되어, 대화만으로 동료를 찾아내고 신분을 위조해 빠져나가는 브라우저 잠입 게임.

플레이어는 레지스탕스 공작원입니다. 무기도 체력바도 없습니다. 가진 것은 대화 하나뿐이고, 상대는 전부 생성형 AI가 실시간으로 굴리는 인물입니다. 누가 동료인지, 상대가 무엇을 감추는지, 내 거짓말이 들키지 않았는지 — 판단의 재료가 매번 새로 만들어지기 때문에 같은 판이 두 번 나오지 않습니다.

1. 게임 방법

목표

네 개의 구간을 차례로 통과해 도시를 빠져나가는 것이 최종 목표입니다. 구간마다 클리어 조건이 서로 다르고, 각 조건마다 AI가 다른 방식으로 개입합니다.

구간클리어 조건AI가 하는 일
튜토리얼
레지스탕스 본부		 동료들의 힌트를 조합해 접선 코드를 알아낸다 NPC 자유 대화 + 접선 코드 정답 판정(동의어 인정)
스테이지 1
증기 도시 거리		 동료 5인이 흘린 연상 단어를 역추론해 접선 코드를 맞힌다 동료별 연상 단어 생성 · 중복 판정 · 정답 판정
스테이지 2
부르주아 저택		 동료 3인과 민간인 5인을 대화만으로 가려내고 열쇠를 얻는다 발언 하나하나의 성향 판정 — 호감도/의심도 증감
스테이지 3
지하 배수로		 신형 로봇 에바의 1:1 심문 8문을 신분을 연기해 방어한다 질문 생성 + 이중 판정(거짓·모순·모호)

조작

키동작
방향키 / WASD이동
E인물·오브젝트와 상호작용 (자유 대화 시작)
F접선 — 연상 단어(단서) 확인 및 접선 코드 입력
C단서 수첩 열람
R감옥의 붙잡힌 동료 구출 (경계 레벨 +1)
Enter대화 전송 / 접선 코드 제출
Space / Esc대화창 닫기

대화는 선택지가 아니라 자유 입력입니다. 무엇을 물어볼지는 플레이어가 직접 씁니다.

종료 조건

결과발생 조건
클리어스테이지 3에서 에바의 심문 8문을 모두 방어
게임 오버 — 검문거리에서 경비 로봇 검문에 적발되고 자석 수류탄이 0개일 때
게임 오버 — 밀고저택에서 민간인의 의심도가 임계에 도달해 밀고당했을 때
게임 오버 — 심문 실패탐지 게이지 소진 · 모순 적발 · 거짓 2회 · 에바의 신분 추리 적중

2. 실행 방법

① 브라우저에서 바로 플레이 (권장 — 설치 불필요)

플레이 링크
https://web-production-6923e.up.railway.app
링크를 열면 바로 시작합니다. 설치·로그인·API 키 입력이 필요 없습니다.
정적 호스팅(GitHub Pages)이 아닌 이유. 이 게임은 매 턴 Claude API를 호출하며, 그 API 키는 서버에만 있어야 합니다. 정적 호스팅에 올리면 키가 브라우저 번들에 들어가 누구나 열람할 수 있게 됩니다. 그래서 Express 서버가 API 키를 쥐고 클라이언트를 함께 서빙하는 형태로 배포했으며, 심사자 입장의 사용법은 동일합니다 — 링크 클릭 한 번입니다.

② 소스에서 직접 실행

저장소: github.com/LeeDoik/codename-clockbird (공개)

사전 준비

  1. Node.js 22 이상
  2. Git LFS — 그림·영상이 LFS에 있습니다. 클론 후 한 번 실행해 주세요. 
    git lfs install
git lfs pull
    ⚠ 이 단계를 건너뛰면 게임 화면이 통째로 비어 보입니다. 그림 자리에 130바이트짜리 포인터 텍스트가 들어오기 때문입니다.
  3. Anthropic API 키 — .env.example을 .env로 복사한 뒤 키 입력 
    ANTHROPIC_API_KEY=sk-ant-...

실행

npm install
npm run build
npm start
# → http://localhost:3000

Windows에서는 play.bat 더블클릭 한 번으로 위 과정이 전부 실행됩니다.
