태엽새 / HEART OF STEEL

게임 소개 및 설명 문서 · 코드네임 codename-clockbird

강철 로봇이 점령한 도시에서, 로봇은 할 수 없는 사람만의 방식으로 동료와 접선하고 임무를 완수하라.

당신은 저항군의 일원입니다. 로봇의 감시가 삼엄한 도시에서, 그들의 눈을 피해 동료를 만나세요.

동료를 만났다고 해서 끝이 아닙니다. 로봇은 흉내 낼 수 없는 방식으로 자신을 증명해야 합니다.

이 도시의 인물들은 정해진 대사를 읽지 않습니다. 생성형 AI가 실시간으로 움직이기 때문에 사람처럼 사고하고 반응합니다.

그래서 동료를 찾고 자신을 증명하는 과정이 매번 새로운 경험이 됩니다.

1. 게임 방법

목표

네 개의 구간을 차례로 통과해 도시를 빠져나가는 것이 최종 목표입니다. 구간마다 클리어 조건이 서로 다르고, 각 조건마다 AI가 다른 방식으로 개입합니다.

구간클리어 조건AI가 하는 일
튜토리얼
레지스탕스 본부		 동료들의 힌트를 조합해 접선 코드를 알아낸다 NPC 자유 대화 + 접선 코드 정답 판정(동의어 인정)
스테이지 1
증기 도시 거리		 동료 5인이 흘린 연상 단어를 역추론해 접선 코드를 맞힌다 동료별 연상 단어 생성 · 중복 판정 · 정답 판정
스테이지 2
부르주아 저택		 동료 3인과 민간인 5인을 대화만으로 가려내고 열쇠를 얻는다 발언 하나하나의 성향 판정 — 호감도/의심도 증감
스테이지 3
지하 배수로		 신형 로봇 에바의 1:1 심문. 8개의 질문에 대해 자신이 선택한 직업을 연기해 방어한다 질문 생성 + 이중 판정(거짓·모순·모호)

조작

키동작
방향키 / WASD이동
E인물·오브젝트와 상호작용 (자유 대화 시작)
F접선 — 연상 단어(단서) 확인 및 접선 코드 입력
C단서 수첩 열람 (스테이지 1)
R감옥의 붙잡힌 동료 구출 (경계 레벨 +1)
Enter대화 전송 / 접선 코드 제출
Space / Esc대화창 닫기

대화는 선택지가 아니라 자유 입력입니다. 무엇을 물어볼지는 플레이어가 직접 씁니다.

종료 조건

결과발생 조건
클리어스테이지 3에서 에바의 8개의 질문에 대해 모두 통과.
게임 오버 — 검문거리에서 경비 로봇 검문에 적발되고 자석 수류탄이 0개일 때
게임 오버 — 밀고저택에서 민간인의 의심도가 임계에 도달해 밀고당했을 때
게임 오버 — 심문 실패탐지 게이지 소진 · 모순 적발 · 거짓 2회 · 에바의 신분 추리 적중

① 브라우저에서 바로 플레이

② 소스에서 직접 실행

저장소: github.com/LeeDoik/codename-clockbird (공개)

사전 준비

  1. Node.js 22 이상
  2. Git LFS — 그림·영상이 LFS에 있습니다. 클론 후 한 번 실행해 주세요. 
    git lfs install
git lfs pull
  3. Anthropic API 키 — .env.example을 .env로 복사한 뒤 키 입력 
    ANTHROPIC_API_KEY=sk-ant-...

실행

npm install
npm run build
npm start
# → http://localhost:3000

Windows에서는 play.bat 더블클릭 한 번으로 위 과정이 전부 실행됩니다.
