# 타이틀 화면 배경

`title-city.png` — 타이틀 화면(src/client/ui/TitleScreen.js · index.html #title)의 도시 배경.

원본은 클로드 디자인 프로젝트(태엽새)의 `assets/title-city.png` (2752×1536, 픽셀 아트
증기 도시)다. 디자인 동기화 API 는 256KiB 이 넘는 파일을 읽지 못해 저장소로 가져올 수
없었다 — claude.ai/design 프로젝트에서 그 파일을 내려받아 여기 `title-city.png` 로
놓으면 코드 수정 없이 그대로 붙는다.

없어도 게임은 돌아간다: 타이틀은 가죽 그라디언트 배경으로 뜬다
(public/intro 의 "그림이 없어도 돌아간다" 규약과 같다).
