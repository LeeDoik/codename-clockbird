저택 인물 (스테이지 2) ● 저장 안 됨

성향 판정(mansion-stance)과 저택 대화(mansion-dialogue)에 {{backstory}} {{personality}} 로 주입됩니다.
첫 문장은 플레이어가 그 인물에게 처음 듣는 말입니다 — 동료는 여기에 반브루주아 뉘앙스를 옅게 깔아 두는 것이 이 스테이지의 유일한 단서입니다.

신형 로봇 '꼬마' (스테이지 3) ● 저장 안 됨

심문 질문(escape-question)과 로봇 판정·대사(escape-robot-judge) 두 프롬프트에 {{backstory}} {{personality}} 로 주입됩니다. 첫 반전 대사(greet/reveal)는 연출용 고정 텍스트라 여기서 편집하지 않습니다.
⚠ 꼬마는 플레이어가 고른 신분 단어를 모르는 쪽입니다. 여기에 "상대의 직업을 추측하라" 같은 판정 규칙을 적지 마세요. 판정 규칙은 프롬프트 쪽에 이미 있고, 여기는 말투와 배경만입니다 — 흐려지면 이 심문의 정보 격리(로봇이 신분 단어를 모르는 설계)가 무너집니다.

시스템 프롬프트 ● 저장 안 됨

게임의 모든 LLM 호출이 쓰는 시스템 프롬프트입니다. 스테이지별로 탭이 나뉘어 있고, 탭 이름 뒤의 ● 는 아직 저장하지 않은 변경이 있다는 뜻입니다. 저장은 지금 열려 있는 탭 하나만 반영됩니다.

접선 코드 단어 풀 ● 저장 안 됨

스테이지 시작 때 이 풀에서 무작위로 접선 코드가 뽑힙니다. 분류·단어 모두 추가·삭제·수정 가능.
분류 이름과 글자 수는 플레이어에게 힌트로 공개되니, 분류 이름이 정답을 좁혀주는 정도도 난이도 레버입니다.

연상 단어 미리보기

코드 단어를 넣고 생성해 보세요. 1인 ≈ 5초, 전원 ≈ 15~25초.

자유 대화 미리보기 — 선택된 NPC 초안으로 실행

단어와 질문을 넣고 실행해 보세요. ≈ 2~5초.

저택 대화 미리보기 — 위에서 선택한 저택 인물 초안으로 실행

게임에서는 대화와 성향 판정이 나란히 돌지만 여기서는 갈라 놓았습니다 — 대사가 이상한 건지 판정이 이상한 건지 가려야 하기 때문입니다.
호감도·의심도 수치는 게임 화면에 절대 안 나갑니다(대사에 숫자가 새면 이 스테이지가 깨집니다). 연기의 온도만 정하므로 여기서 단계를 바꿔 보세요.
저택 인물 탭에서 사람을 고르고 실행해 보세요. ≈ 2~5초.

심문 미리보기 (스테이지 3)

두 판정을 한 번에 돌려 나란히 보여줍니다. 이 심문의 설계 전체가 "시스템은 신분 단어를 알고 로봇은 모른다"는 정보 격리에 걸려 있어서, 따로 보면 그게 지켜지는지 알 수 없습니다. 로봇 쪽에는 신분 단어를 넘길 자리 자체가 없습니다(judgeAsRobot 의 시그니처가 그렇습니다) — 로봇의 대사에 신분 단어가 나오면 그건 프롬프트가 유추를 유도한 것입니다.
질문과 답변을 넣고 실행해 보세요. ≈ 3~8초.
