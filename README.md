## 1. 한눈에 보기

플레이어는 레지스탕스 공작원입니다. **무기도 체력바도 없습니다.** 가진 것은 대화 하나뿐이고,
상대는 전부 생성형 AI가 실시간으로 작동시키는 인물입니다. 누가 동료인지, 상대가 무엇을 감추는지,
내 거짓말이 들키지 않았는지 — **판단의 재료가 매 판 새로 만들어지므로 같은 판이 반복되지 않습니다.**

네 개의 구간을 차례로 통과해 도시를 빠져나가는 것이 최종 목표입니다.
구간마다 클리어 조건이 다르고, **조건마다 AI가 다른 방식으로 개입합니다.**

| 구간 | 클리어 조건 | AI가 하는 일 |
|---|---|---|
| **튜토리얼** 레지스탕스 본부 | 동료들의 힌트를 조합해 접선 코드를 알아낸다 | NPC 자유 대화 + 접선 코드 정답 판정(동의어 인정) |
| **스테이지 1** 증기 도시 거리 | 동료 5인이 흘린 연상 단어를 역추론해 접선 코드를 맞힌다 | 동료별 연상 단어 생성 · 중복 판정 · 정답 판정 |
| **스테이지 2** 부르주아 저택 | 동료 3인과 민간인 5인을 대화만으로 가려내고 열쇠를 얻는다 | 발언 하나하나의 성향 판정 — 호감도/의심도 증감 |
| **스테이지 3** 지하 배수로 | 신형 로봇 에바의 1:1 심문. 8개 질문에 대해 자신이 고른 직업을 연기해 방어한다 | 질문 생성 + 이중 판정(거짓·모순·모호) |

대화는 선택지가 아니라 **자유 입력**입니다. 무엇을 물어볼지는 플레이어가 직접 씁니다.

## 3. AI 활용 요약

모든 호출은 **서버에서만** 일어납니다. 접선 코드·신분 단어 같은 정답은 클라이언트로 내려가지 않습니다.

| 어디에 | 모듈 | 모델 | 무엇을 |
|---|---|---|---|
| 스테이지 1 단서 | `ai/wordGen.js` | `claude-sonnet-5` | 접선 코드에서 동료 5인의 연상 단어를 **1인당 독립 호출**로 생성 |
| 스테이지 1 판정 | `ai/judge.js` | `claude-sonnet-5` | 연상 단어 중복·유사어 판정 / 접선 코드 정답 판정(동의어 인정) |
| 전 구간 대화 | `ai/dialogue.js` | `claude-haiku-4-5` | NPC 자유 대화 — 페르소나 유지, SSE 스트리밍 |
| 스테이지 2 판정 | `ai/disposition.js` | `claude-haiku-4-5` | 플레이어 발언의 성향 판정 → 호감도/의심도 증감 |
| 스테이지 3 심문 | `ai/interrogation.js` | `haiku-4-5` + `sonnet-5` | 질문 생성(haiku) + **시스템/로봇 이중 판정**(sonnet) |
| 안전장치 | `ai/guardrail.js` | — | 코드 단어 유출 필터 · 단어 정규화 |

**심문의 이중 판정**이 스테이지 3 설계의 핵심입니다. 시스템 판정자는 플레이어의 진짜 신분 단어를
알고 모순을 잡지만, 에바(로봇) 역할의 모델은 **그것을 모르는 상태로** 대사를 만듭니다.
정보 격리를 깨면 로봇이 답을 아는 채로 심문하게 되므로, 판정을 둘로 갈라 놓았습니다.

프롬프트 10종은 전부 `src/data/prompts/*.txt`에 텍스트로 분리돼 있어 **코드 수정 없이 튜닝**할 수
있습니다 (아래 **프롬프트 스튜디오** 항목 참고).
설계 의도·프롬프트 전문·실측은 별도 제출하는 「AI 활용 기술 문서」에 있습니다.

## 4. 로컬 실행

> 심사에는 **[플레이 링크](https://web-production-6923e.up.railway.app)** 를 권장합니다. 아래는 소스에서 직접 돌릴 때입니다.

### 사전 준비

1. **Node.js 22 이상** ([nodejs.org](https://nodejs.org))
2. **Git LFS** ([git-lfs.com](https://git-lfs.com)) — 그림·영상이 LFS에 있습니다. 클론한 뒤 한 번:

   ```bash
   git lfs install
   git lfs pull      # 이미 LFS 없이 클론했다면
   ```

   > ⚠ 이걸 건너뛰면 **게임 화면이 통째로 비어 보입니다.** 배경·스프라이트 자리에
   > 그림 대신 130바이트짜리 포인터 텍스트가 들어오기 때문입니다. 파일 크기가
   > `src/client/assets/street-bg.png` 기준 3.7MB가 아니라 1KB 미만이면 이 경우입니다.

3. **Anthropic API 키** — [console.anthropic.com](https://console.anthropic.com/settings/keys) 에서 발급
4. `.env.example` 을 `.env` 로 복사한 뒤 키를 입력:

   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```

### 실행

```bash
npm install
npm run build
npm start
```

→ 브라우저에서 http://localhost:3000

Windows에서는 **`play.bat` 더블클릭** 한 번으로 위 과정이 전부 실행됩니다.

### 개발 모드

```bash
npm run dev      # Vite HMR + Express API 동시 기동 → http://localhost:5173
```

**개발 모드 전용** 진입 링크 — 원하는 구간으로 곧장 들어갑니다:
`?tutorial` (본부) · `?stage2` (저택) · `?stage3` (수로) · `?ending` (엔딩)

빌드 모드에서도 도는 지름길: `?nointro` (오프닝 건너뛰기) · `?notutorial` (본부 훈련 건너뛰기)

```
src/

    ui/                대화창·단서 수첩·HUD·심문 게이지 (한글 IME·스트리밍 대응)

    assets/            맵 배경 · 충돌 격자(*-props.json) · 타일 · 캐릭터  [Git LFS]
  server/              Express 5 — API 키 보관 + 세션·정답 보관
    ai/
      client.js        Claude 클라이언트 + 모델 상수
      wordGen.js       연상 단어 생성 (동료 1인당 독립 호출, structured outputs)
      judge.js         중복·유사어 판정 / 접선 코드 정답 판정
      dialogue.js      NPC 자유 대화 (SSE 스트리밍)
      disposition.js   저택 발언 성향 판정
      interrogation.js 심문 질문 생성 + 시스템/로봇 이중 판정
      guardrail.js     코드 단어 유출 필터 · 단어 정규화
      promptStore.js   프롬프트 파일 로드 (스튜디오 저장을 다음 판부터 반영)
    routes/            stage · mansion · escape · tutorial · studio
    *Session.js        인메모리 세션 — 접선 코드·신분 단어는 여기에만 존재
  data/                코드 단어 풀 · NPC 페르소나 · 프롬프트 10종  (서버 전용)
public/                런타임 로드 에셋 — 오프닝 · 초상 26종 · UI · 오디오 19종  [Git LFS]
```

### 보안 설계

- `ANTHROPIC_API_KEY` 는 **서버에서만** 로드됩니다. Vite는 `VITE_` 접두사 변수만 번들에 노출하므로 키가 클라이언트로 새지 않습니다.
- **접선 코드는 클라이언트로 전송되지 않습니다.** 세션 모듈에만 보관되고 정답 판정도 서버에서 수행합니다. 개발자도구로 정답을 볼 수 없습니다.
- 코드 단어 풀·페르소나·프롬프트(`src/data/`)도 서버에서만 읽습니다.
- 프롬프트 스튜디오는 **개발 모드 전용**입니다 — 제출 빌드(`npm start`)에서는 페이지·API 모두 403으로 잠깁니다.

<details>
<summary><b>개발 노트 — 설계 근거 (실측)</b></summary>

- **연상 단어는 동료 1인당 1회 독립 호출** 로 생성한다. 5인을 한 번에 생성하면 모델이
  서로를 의식해 단어를 분산시켜 중복이 사라지고, 체포·구출 메커닉 전체가 죽는다.
  독립 생성 시 중복률은 표기 일치 기준 **약 25%** (여기에 LLM 유사어 판정이 더해진다).
  난이도 조정은 `scripts/exp-dup-rate.js` (`npm run exp:diff`) 로 측정하며 진행한다.
- **연상 단어를 "직접적으로" 몰면 역효과다.** 단서가 친절해질수록 5인의 단어가 겹쳐
  중복(체포)이 폭등해 오히려 못 푸는 판이 된다. 난이도는 대화·판정 쪽 레버로 조정한다.
- **동시 실행은 3개로 제한** (`wordGen.js` 의 `CONCURRENCY`). 5개를 한꺼번에 쏘면
  529 Overloaded 로 실패하는 것을 실측 확인했다. 3개면 스테이지 시작에 약 11~20초.
- **`thinking: { type: 'disabled' }`** 를 명시한다. Sonnet 5 는 생략 시 adaptive thinking 이
  켜져 있어 지연이 2배가 된다 (33초 → 17초). 연상 단어 생성에는 깊은 추론이 불필요하다.
- **`maxRetries: 5`** (`client.js`). 호출 하나만 실패해도 스테이지 시작이 통째로 실패하므로
  기본값 2보다 넉넉히 잡는다.
- **대화 프롬프트에 접선 코드를 넣지 않는다** (`dialogue.js`). 계획서 초안은 "응답에 코드가
  있으면 재생성"이었으나 스트리밍에서는 필터가 감지한 시점에 이미 화면에 찍힌 뒤다.
  모델이 모르는 정보는 유출될 수 없으므로, NPC 에게는 자기 연상 단어만 알려준다.
- **심문은 시스템 판정과 로봇 대사를 갈라 놓는다** (`interrogation.js`). 같은 이유다 —
  로봇이 신분 단어를 알면 심문이 성립하지 않는다. 판정만 정답을 안다.
- **프롬프트 캐싱은 걸지 않았다.** Haiku 4.5 의 최소 캐시 프리픽스는 4096 토큰인데
  대화 시스템 프롬프트는 500 토큰 남짓이라 `cache_control` 을 붙여도 조용히 무시된다.
  대화 이력이 길어져 프리픽스가 4096 토큰을 넘기면 그때 도입한다.

</details>

<details>
<summary><b>개발 노트 — 구현 메모 (함정)</b></summary>

- **structured outputs**: SDK `@anthropic-ai/sdk@0.71.x` 기준으로
  `client.beta.messages.parse({ output_format: betaZodOutputFormat(schema) })` 형태를 쓴다.
  이 버전은 최상위 `output_format` 필드를 받으며, `parse()` 가 `structured-outputs-2025-11-13`
  베타 헤더를 자동으로 붙인다. (SDK 소스 확인 결과 — `output_config.format` 은 이 버전의
  `parse()` 가 읽지 않는다.) SDK 업그레이드 시 재확인 필요.
- **zod 는 반드시 v4** 여야 한다. SDK 의 `betaZodOutputFormat` 이 `z.toJSONSchema()` 를
  호출하는데, 이는 zod v4 API 다. zod 3.25.x 의 루트 export 는 아직 v3 라
  `z.toJSONSchema is not a function` 으로 실패한다 (SDK peer 범위가
  `^3.25.0 || ^4.0.0` 이라 설치 시 경고가 없으니 주의).
- **ESM**: 프로젝트 전체가 `"type": "module"` 이다. `__dirname` 대신
  `fileURLToPath(import.meta.url)` 을 쓴다.
- **Express 5**: `app.get('*')` 는 path-to-regexp v8 에서 에러가 난다. SPA 폴백은
  `app.use()` 미들웨어로 구현돼 있다.
- **화면·맵 축척**: 캔버스는 1920×1080 (16:9). 월드는 메인 카메라가 2배 줌으로 그리고
  (보이는 월드 = 30×16.875 칸, 맵 최소 30×17 칸), HUD·수첩은 별도 UI 카메라가 1080p
  원본으로 그린다. 맵 json 의 `charHeight` 와 `cameraZoom` 이 걷는 속도·상호작용 사거리·
  말풍선 높이·발밑 판정을 전부 좌우한다.
- **충돌은 `scripts/walkmask.js` 의 walk 격자가 유일한 출처**다 (`*-props.json`).
  칸 수가 맵과 어긋나면 `los.readWalk` 가 던진다 — 조용히 옛 좌표로 되돌아가지 않는다.
- **`scripts/gen-*-art.js` · `gen-*-map.js` 는 옛 계보다.** 다시 돌리면 현재 아트를
  덮어쓴다 (각 파일 머리에 경고를 달아 뒀다).

</details>
